Map tools

Hotkeys

  • SHIFT + MOUSE – Line selection
  • M – Toggle polygon/line
  • B – Bouncy
  • D - Death
  • N – Non-bouncy
  • X – Delete
  • Arrow keys – Move line
  • CTRL Z – Delete last line
  • CTRL A – Select all
  • CTRL C – Copy map
  • CTRL V – Paste map
  • CTRL D – Drawing mode
  • [ ] – Move to back/front
  • G – Auto-generate pop-up
